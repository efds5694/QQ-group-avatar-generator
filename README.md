# QQ 群头像生成器

一个轻量、纯前端的 QQ 群头像制作工具。输入群名或简称，选择排版、字体和配色，即可实时生成适合 QQ 圆形裁切的正方形头像，并导出为 PNG 图片。

所有处理均在浏览器本地完成，文字内容和生成的图片不会上传到服务器。

## 功能

- 支持横向、纵向两种文字排版。
- 支持手动换行和自动换行，可设置每行或每列的字数。
- 支持微软雅黑、黑体、思源黑体、楷体、宋体、仿宋、Arial、Impact、Georgia 等字体选项。
- 可调整字号、字重和字间距，并提供“贴合圆形”自动适配字号。
- 支持背景色、文字色和边框色的颜色选择器、RGB 数值调节及十六进制显示。
- 提供推荐配色、随机高对比配色，以及自动选择黑色或白色文字的功能。
- 支持无边框、实线、虚线、点线、双线和点划线等圆形边框样式。
- 支持添加多条顶部或底部附加文字，并分别设置字体、字号、字重、字间距和颜色。
- 支持批量调整所有附加文字的样式和位置。
- 可开启自动避让，避免中心文字与附加文字重叠或超出圆形区域。
- 支持导出 `512 × 512`、`1024 × 1024` 和 `2048 × 2048` PNG 图片。
- 预览区域会用深色四角模拟 QQ 的圆形头像裁切效果，下载结果仍是完整正方形。
- 响应式布局，支持桌面端和移动端浏览器使用。

## 使用方法

### 直接打开

双击打开 [QQ群头像生成器.html](./QQ群头像生成器.html)，或将它拖入现代浏览器中即可使用。

### 使用本地静态服务器

如果浏览器对本地文件有额外限制，也可以在项目目录启动任意静态文件服务器。例如：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>，点击打开 `QQ群头像生成器.html`。

## 操作说明

1. 在“文字内容”中输入群名或简称。输入框最多支持 40 个字符，也可以直接回车换行。
2. 在“排版样式”中选择文字方向、字体、字号、字重和字间距。
3. 开启“自动换行”后，使用滑块设置每行或每列最多显示的字数。
4. 在“RGB 配色”中设置背景色和文字色。对比度提示可帮助判断文字是否清晰。
5. 如需装饰，在“圆形边框”中选择边框样式，并设置粗细与颜色。
6. 如需添加顶部或底部标识，点击“添加文字”，再编辑附加文字卡片中的内容和样式。
7. 在右侧预览确认效果，选择导出尺寸后点击“下载 PNG 头像”。

## 技术实现

- HTML5
- CSS3（响应式布局、CSS Grid、渐变、圆角和自适应界面）
- 原生 JavaScript
- HTML Canvas 2D API（文字、附加文字、边框和 PNG 导出）

项目没有使用框架、第三方库、构建工具或后端服务，下载文件后即可离线运行。

## 注意事项

- 字体效果取决于当前设备已安装的字体。若某字体未安装，浏览器会自动使用后备字体。
- QQ 最终会以圆形显示头像，建议通过预览中的安全区域确认文字和边框不会贴近角落。
- 导出的图片是完整正方形 PNG，不包含预览中的深色圆形裁切遮罩。
- 2048 × 2048 导出尺寸会生成更大的图片文件，适合需要更高分辨率的场景。
